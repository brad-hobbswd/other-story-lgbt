Accessibility

The goal of this website is to provide a readable, usable experience for visitors across a range of devices and access needs.

Accessibility efforts

The site is designed with responsive layouts, readable text, semantic page structure, keyboard-accessible navigation, visible focus indicators, and descriptive text alternatives for meaningful images where available. The site will continue to be reviewed as pages and features are updated.

Report an accessibility barrier

Should you encounter a page or feature that is difficult to use with a keyboard, screen reader, magnification, or another assistive technology, please contact the author through a contact method published on the website or by the publisher. Include the page address and a brief description of the barrier so the issue can be reviewed.

Ongoing improvement

Accessibility is an ongoing effort. Feedback is welcome and will help guide improvements to the website.
